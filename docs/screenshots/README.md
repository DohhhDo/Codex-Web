## 自己截图 / Capture your own

```bash
npm ci
npm run build:client
npm run demo
```

Open `http://localhost:3002`. Use `/?theme=light`, `/?theme=dark`, or `/?home=1` to switch scenes. See [demo instructions](../../scripts/demo/README.md).
