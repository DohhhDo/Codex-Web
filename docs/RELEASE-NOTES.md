# Codex-Web · 独立仓库首发 / Independent repository launch

## 中文

Codex-Web 是由 DOhhhDO 独立维护的 Codex 浏览器工作区，基于 CloudCLI v1.37.3 衍生开发，保留 AGPL-3.0-or-later 许可证与上游归属。

本次整理了 Codex 品牌入口、深浅主题、项目与会话侧栏、输入框、模型和思考档位菜单、通知设置及终端外观。输入框下方可查看 Token、缓存命中率、订阅级别，以及服务端返回的套餐额度。

仓库提供中英文介绍、15 张示例截图和独立截图站。示例站使用 DOhhhDO 账号、原创宇航猫头像、5 个项目和 18 段虚构会话，不调用真实模型。

当前以源码运行的 Web 版本为交付范围，未发布独立 npm 包、Docker 镜像或桌面安装包。

## English

Codex-Web is an independently maintained browser workspace for Codex by DOhhhDO, derived from CloudCLI v1.37.3 with upstream attribution and AGPL-3.0-or-later licensing preserved.

This initial repository release includes Codex-focused branding, light and dark themes, project and session navigation, a redesigned composer, model and reasoning menus, notification settings, and terminal theming. The composer footer displays token usage, cache hit rate, subscription tier, and account allowance windows when reported by the provider.

The repository includes Chinese and English introductions, 15 example screenshots, and a separate demo site. Its fictional DOhhhDO account, original astronaut-cat avatar, five projects, and eighteen conversations do not require live model calls.

The current delivery is the web application run from source. No independent npm package, Docker image, or desktop installer is published.
