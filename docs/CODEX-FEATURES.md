# Codex 功能补全

先补功能，页面视觉调整单独进行。`/goal`、`/plan` 是入口示例，不是本次范围的全部。

## 已接入的功能

| 功能 | 使用方式与行为 |
| --- | --- |
| 计划 | `/plan` 切换计划模式，`/plan off` 退出；原生计划结束后由用户选择实施或继续修改。 |
| 目标 | `/goal 目标内容`；可用 `/goal --budget 40000 目标内容` 指定 token 预算。目标进度显示状态、用量和耗时；支持 status、pause、resume、clear。续跑由 Codex 原生运行层负责。暂停阻止后续续跑；停止按钮中断当前轮并暂停目标。 |
| 运行中追加指令 | `/steer 指令` 直接进入当前轮；收到服务器确认后才清空草稿。普通后续消息仍进入已有队列。 |
| 审查与压缩 | `/review` 原生审查未提交修改，也可附带审查说明；`/compact` 调用原生上下文压缩。 |
| 模型与上下文 | `/model`、`/models` 选择模型；模型和推理强度来自实时目录，保留自定义模型与离线目录。`/context`、`/cost` 查看用量，区分当前上下文、累计 token 和账号配额。 |
| 项目记忆 | `/memory` 打开 Codex 项目的 `AGENTS.md`；自定义 Codex 提示词从项目和用户的 `.codex/prompts` 发现。 |
| Skills、Apps、MCP | `/skills`、`/apps`、`/mcp` 查看原生可用项。Skill 插入 `$名称`，可用应用插入 `@app:ID`；服务端解析真实路径与原生 mention。MCP 提问支持表单与 URL 确认。 |
| 交互审批 | 命令、文件修改、扩展权限、结构化提问保留等待状态；刷新可恢复待答请求，过期请求不能再被批准。提问按稳定 ID 回传，支持多选和保密输入。 |
| 流式过程 | 文本、思考、命令输出、文件差异、计划步骤按原生事件更新。搜索结果可打开来源；图片结果可查看、下载，并在历史记录中恢复。 |
| 子代理 | 展示多个子代理的状态与结果；`/agents` 查看当前会话的子代理，可停止正在运行的子代理。 |
| 重复任务 | `/automations` 创建、编辑、暂停、恢复、删除重复任务，并查看运行记录。任务保存到数据库，按创建时的模型和权限执行；忙碌会话延后，错过多个周期只补跑一次，重启会标记未完成的运行。 |
| 研究、图片、浏览器 | `/research 描述`、`/image 描述`、`/browser 描述` 显式调用对应已启用的技能。未安装或未启用时返回具体错误。 |
| 双向语音 | `/voice` 打开实时语音，浏览器通过 WebRTC 连接原生语音服务。关闭、断线及晚到的麦克风授权都会清理资源；语音取消不会中断普通任务。 |
| 产物 | `/artifacts` 汇总会话中的文件产物，复用现有编辑、预览及下载功能；HTML 预览继续使用隔离 iframe。 |

输入 `/` 可检索全部命令，计划和目标入口排在前面；需要参数的命令只补全输入，不会直接启动任务。

## 验证与适用条件

2026-09-10 检查：前端 440 项通过，后端 433 项通过、1 项跳过；类型检查、生产构建通过，lint 无错误（仍有 React 等规则警告）。

- 使用项目固定依赖 `@openai/codex` 0.153.4 生成的 TypeScript 协议核对字段。
- 真实 CLI 已验证模型发现、独立临时 CODEX_HOME 中的目标 set/get/clear，以及完全本地模拟模型服务上的三轮原生续跑和暂停。
- 运行层测试覆盖新建/恢复、权限模式、早到的完成事件、流式输出、审批与过期、计划确认、目标续跑、语音生命周期、子代理、图片、搜索和用量。
- 前端交互测试覆盖控制确认、语音资源清理和安全来源链接；桌面和手机浏览器验证覆盖 15 个 Codex 专属命令、参数补全、计划切换、Skill 插入、重复任务保存和目标进度。
- 生成图片、研究、浏览器工作依赖对应技能及其工具；实时语音依赖浏览器麦克风/WebRTC 和账号能力。未向外部模型发送付费生成请求，也未验证真实账号的双向语音或这些工作流的生成质量。
- 重复任务要求 Codex-Web 服务运行；审批仍需用户处理，不会因后台执行而自动放行。复杂嵌套 MCP 表单目前显示不支持并允许拒绝，避免提交不完整授权。
